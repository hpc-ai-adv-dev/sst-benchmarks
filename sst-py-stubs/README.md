# sst-py-stubs

`sst-py-stubs` is a plain stub-only distribution for SST's embedded `sst`
Python module.

It installs a top-level `sst` package containing `__init__.pyi` and `py.typed`
so editors and type checkers can offer completions and signatures for SST model
construction code.

## Usage

Install from this repository checkout:

```bash
python3 -m pip install .
```
